# STAIR_FOLDED — บันไดพับผ้าพาดทางยาว

เว็บแอพวิเคราะห์และออกแบบบันไดคอนกรีตเสริมเหล็กแบบพับผ้า (folded plate) พาดทางยาว เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไร เปิดในเบราว์เซอร์ได้เลย

## ความสามารถ

- **เรขาคณิตหลายช่วง** — เรียงช่วงบันไดกับชานพักได้หลายช่วงตามแนวตรง แต่ละช่วงกำหนด R, T, n, t เองได้ พร้อมรูปตัดตามสเกลจริง
- **โมเดลวิเคราะห์** — วิเคราะห์บนภาพฉายราบ ต่อความกว้าง 1 m ด้วย direct stiffness method รองรับ support แบบ Pin / Roller / Fixed หลายจุด ลากย้ายตำแหน่งได้
- **น้ำหนักบรรทุก**
  - DL (น้ำหนักคอนกรีตลูกตั้ง ลูกนอน ชานพัก) คำนวณอัตโนมัติ
  - SDL / LL กรอกเองแยกทีละช่วง
  - เพิ่ม Point / UDL / Moment เองได้ และกดปิดแรงชั่วคราวได้โดยไม่ต้องลบ
- **Load Combination** — กำหนด factor DL / SDL / LL ได้ (ค่าเริ่มต้น 1.4 / 1.4 / 1.7)
- **ผลวิเคราะห์** — Reaction (ต่อ 1 m และรวมทั้งความกว้าง), Shear & Moment ที่ support, SFD, BMD
- **ตรวจการแอ่นตัว** — ทันที / ระยะยาว ตาม ACI 318-19 พร้อมกราฟการแอ่นตัว
- **อ่านค่าบนกราฟ** — เลื่อน cursor (หรือแตะบนมือถือ) บน SFD / BMD / กราฟการแอ่นตัว
- **ออกแบบ SDM**
  - เหล็กล่าง เหล็กบน และเหล็กกระจาย แยกทีละช่วง
  - ตรวจแรงเฉือน และความหนาต่ำสุดตาม ACI
- **รูปประกอบเหล็กเสริม** — เหล็กปลอกเสริมหลักรอบลูกนอน/ลูกตั้ง ปลายงอ 135° พร้อมเหล็กช่วยยึดที่มุมปลอก มีรูปตัดทั้งบันได กับรูปขยายจุดต่อล่างและจุดต่อบน
- **ช่องกรอกรับสูตรคำนวณ** — พิมพ์ `+ - × ÷ ( )` ได้ เช่น `0.1*1.7`
- **โหมดกลางวัน / กลางคืน**
- **รายการคำนวณ PDF** — ปุ่มท้ายโปรแกรมสร้างไฟล์ PDF A4: ข้อมูลออกแบบ รูปตัด น้ำหนัก combination ผลวิเคราะห์ ขั้นตอนออกแบบเหล็ก แรงเฉือน การแอ่นตัว รูปเหล็กเสริม และสรุปผล (ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวสร้าง PDF)
- **Save As / Save** — บันทึกเป็นไฟล์ HTML ที่เก็บค่าที่กรอกไว้ทั้งหมด เปิดไฟล์นั้นแล้วทำงานต่อได้ทันที

## วิธีใช้

**เปิดในเครื่อง:** ดาวน์โหลด `index.html` แล้วเปิดด้วย Chrome หรือ Edge (ปุ่ม Save ทับไฟล์เดิมต้องใช้ Chrome หรือ Edge ส่วนเบราว์เซอร์อื่นจะดาวน์โหลดเป็นไฟล์ใหม่แทน)

**เปิดผ่าน GitHub Pages:**

1. อัปโหลด `index.html` และ `README.md` ขึ้น repository
2. ไปที่ **Settings → Pages**
3. ที่ **Source** เลือก `Deploy from a branch` → branch `main` → โฟลเดอร์ `/ (root)` → **Save**
4. รอสักครู่ แอพจะเปิดได้ที่ `https://<username>.github.io/<repo-name>/`

**ติดตั้งเป็นแอพในเครื่อง (PWA):**

1. เปิดลิงก์ GitHub Pages ด้วย Chrome หรือ Edge
2. กดไอคอน **ติดตั้ง** (⊕) ที่ท้ายช่อง URL หรือเข้าเมนู **⋮ → ติดตั้งแอพ / Install Stair Folded**
3. แอพจะมีไอคอนบน Desktop / Start Menu และเปิดเป็นหน้าต่างของตัวเอง
4. หลังเปิดครั้งแรกแล้ว แอพจะใช้งานแบบออฟไลน์ได้

**อัปเดตเวอร์ชัน:** แก้ `index.html` แล้วเปลี่ยน `APP_VERSION` / `APP_DATE` ในไฟล์ และตั้ง `CACHE` ใน `sw.js` เป็นเลขเดียวกัน (เช่น `stair-folded-v1.5.0`) จากนั้น push ขึ้น repo แอพที่เปิดค้างอยู่จะขึ้นแถบ "มีเวอร์ชันใหม่" ให้กดอัปเดต (ค่าที่กรอกไว้ยังอยู่) และเปิดแอพครั้งถัดไปจะได้เวอร์ชันใหม่เอง

## หน่วย

กำลัง (t), โมเมนต์ (t·m), ระยะ (m), หน่วยแรง (ksc) · แรงลง = ค่าบวก · ผลวิเคราะห์คิดต่อความกว้าง 1 m

## สมมติฐานที่ใช้

- วิเคราะห์บนภาพฉายราบด้วย EI คงที่ — ถ้าเป็น pin + roller ผลจะถูกต้องตรงๆ แต่ถ้ามี support 3 จุดขึ้นไป (indeterminate) ผลจะเป็นค่าประมาณ
- น้ำหนักแผ่นพับผ้า = γ·t·(nR + (n−1)T) / ((n−1)T) ต่อพื้นที่ราบ
- หน้าตัดออกแบบช่วงบันไดใช้ความหนาแผ่น t (แบบอนุรักษ์), d = t − covering − db/2
- As,min = 0.0025bh (fy < 4000 ksc) / 0.0018bh (fy = 4000 ksc) / 0.0018·(4000/fy)·bh ≥ 0.0014bh (fy > 4000 ksc)
- φVc = φ·0.53√f'c·b·d ใช้ |Vu| สูงสุดในช่วง โดยไม่ลดค่าที่ระยะ d
- ความหนาที่ไม่ต้องตรวจการแอ่นตัว (ACI 7.3.1) L/20, L/24, L/28, L/10 × (0.4 + fy/7000) — ถ้าบางกว่านี้ ผลผ่าน/ไม่ผ่านตัดสินจากการคำนวณการแอ่นตัว
- การแอ่นตัว: Ec = 15,100√f'c, fr = 2.0√f'c, Ie ตาม ACI 318-19 ตาราง 24.2.3.5 (คิด Ie รายช่วง), ระยะยาว λΔ = ξ/(1 + 50ρ′), ตรวจ ΔL ≤ L/360 และ ระยะยาว + LL ≤ L/240 หรือ L/480
- ใช้ได้กับบันไดที่วิ่งทางเดียวเป็นแนวตรง ถ้าเป็นบันไดหักกลับแบบ U หรือ L ให้วิเคราะห์ทีละช่วง แล้วเอา reaction ไปใส่เป็นแรงของอีกช่วง

**LL อ้างอิง** — กฎกระทรวงกำหนดการออกแบบโครงสร้างอาคารฯ พ.ศ. 2566 ข้อ 11 (ค่าสำหรับบันได)
